# ekd5-remake — 삼국지 조조전 엔진 재구현

> **English summary** — A clean-room reimplementation of the engine of *Sangokushi Sousouden* (三國志曹操傳, KOEI 1998, Korean release) in Rust, compiled to WebAssembly so the original game runs in a phone browser as a PWA. The engine reads the **original game files**, which are **not included** in this repository. You need your own copy of the game. Behaviour is ported function by function from a Ghidra decompilation of `EKD5.EXE`.

1998년 코에이의 PC 게임 **《삼국지 조조전》** 을 휴대폰 브라우저에서 그대로 즐길 수 있도록, 게임을 돌리는 프로그램(엔진)을 Rust로 새로 만든 프로젝트입니다.

- **에뮬레이터가 아닙니다.** 옛날 윈도를 흉내 내지 않고, 원작 실행 파일이 하던 일을 함수 단위로 뜯어보고 새 코드로 다시 짰습니다.
- **원작 데이터는 그대로 씁니다.** 그림, 음악, 대사, 지도, 전투 스크립트는 원작 파일을 직접 읽습니다. 그 파일들은 이 저장소에 **들어 있지 않습니다**.
- **결과물**: 브라우저에서 돌아가는 웹 앱(PWA)입니다. 홈 화면에 설치하면 앱처럼 전체 화면으로 하고, 터치, 세로 화면, 배속, 저장 칸 5개를 지원합니다.

---

## 비개발자를 위한 한 줄 설명

조조전은 **내용물**(그림, 음악, 대사, 지도)과 그걸 **돌리는 기계**(프로그램)로 나뉩니다. 이 프로젝트는 내용물은 원본 그대로 두고, **기계만 요즘 부품으로 새로 만든 것**입니다. 옛날 LP판은 그대로 두고, 그걸 트는 턴테이블을 새로 만든 셈입니다. 그래서 폰에서도 돌아가고, 원작에 없던 편의 기능도 붙일 수 있습니다.

- **전투**
  - 원작 공식: 피해, 명중, 회심, 반격, 연속 공격, 병종 상성, 지형 효과
  - 책략 연출, 도구, 상태 이상, 컴퓨터 AI 7종
  - 일기토
  - 연출: 레벨업, 데미지 숫자, 퇴각 대사, 회심 외침
  - 장수 정보 창 (능력·장비·책략·장수열전·부대특성), 날씨
- **본진**: 장수를 눌러 대화, 출진 장수 고르기(원작 규칙), 장비 화면(능력치 변화 미리 보기, 아이템 정보), 구입, 매각, 보물도감
- **진행**: 엔딩 3종, 갈림길, 명성, 회차 기록, 관상가 튜토리얼
- **소리**: CD 음악, 효과음
- **웹 편의 기능**
  - 터치 조작(길게 누르기 = 정보), 세로·가로 고정, 배속 ×1, ×1.5, ×2, ×4
  - 저장 칸 5개, 새 버전 알림, 홈 화면 설치 안내

원작과 다르거나 아직 없는 것은 [`AGENTS.md`](AGENTS.md)의 "근사/미구현"에 정리해 두었습니다.

## 어떻게 만들었나

> 전 과정을 기술적으로 자세히 정리한 문서는 **[docs/](docs/README.md)** 에 있습니다: 역공학 준비, 데이터 형식, 스크립트 엔진, 함수 옮기는 법, 시험 체계, 웹·PWA, AI 와 일한 방식, 사례 연구.

### 1. 원작 분석 (역공학)
- `EKD5.EXE`를 [Ghidra](https://ghidra-sre.org/)로 디컴파일했습니다. 전체 덤프와 스크립트 명령 처리 함수 표를 뽑는 Ghidra 스크립트는 [`re/scripts/`](re/scripts)에 있습니다.
- 데이터 형식은 코드와 파일을 대조해 풀었습니다.
  - KOEI 압축 묶음(`Ls12`)
  - 장수·아이템·직업 표(`DATA.E5`)
  - 스크립트 바이트코드(`*.EEX`, 117개 전부 바이트 단위로 정확히 해석)
  - 지도, 스프라이트, 글꼴
- 시제품 도구 `re/tools/ls12.py`, `re/tools/eex.py`로 먼저 확인하고 Rust로 옮겼습니다.
- 디컴파일 결과물(`re/out/`)은 원작에서 나온 것이라 저장소에 넣지 않습니다.

### 2. 함수 단위로 옮기기
- 코드 주석에 원작 함수 주소(`FUN_0043dd5b` 등)를 남겼습니다. 어느 코드가 원작의 어디를 옮긴 것인지 바로 따라갈 수 있습니다.
- 원작의 시간 단위(1/20초)를 엔진 틱(1/30초)으로 환산해 연출 길이까지 맞췄습니다.

### 3. 자동 회귀 시험
- 명령줄 도구(`ekd5-cli`)가 화면 없이 게임을 **처음부터 엔딩까지 자동으로 진행**합니다. 약 42만 틱입니다.
- 무엇을 고칠 때마다 이 시험으로 다른 곳이 망가지지 않았는지 확인했습니다.
- 특정 장면의 스크린샷, 저장 불러오기, 사건 강제 실행 같은 시험 옵션도 있습니다.

### 4. 웹으로 내보내기
- 엔진은 화면, 소리, 입력과 분리된 순수 Rust 라이브러리입니다.
- `ekd5-web`이 이것을 WebAssembly로 감싸고, `web/ekd5.js`가 캔버스, Web Audio, 터치, 저장을 맡습니다.

### 작업 기록
- 2026년 10월 16일부터 20일까지 **5일**, 커밋 **60여 개**, 코드 약 **1만 4천 줄**입니다.
- **Claude Code**(AI 코딩 도구)와 함께 작업했습니다.
  - 사람(저장소 주인)이 원작을 플레이하며 "이게 원작과 다르다", "이게 빠졌다"를 짚었습니다.
  - AI가 디컴파일 코드에서 해당 함수를 찾아 옮기는 방식으로 진행했습니다.
- 커밋 기록에 그 과정이 그대로 남아 있습니다.
  - 첫 커밋: 타이틀 화면
  - 마지막 즈음: 장비 화면, 퇴각 대사, 설치 안내

### 배운 점
- **"원작을 보고 그대로"가 가장 빠릅니다.** 그럴듯하게 지어낸 값은 결국 원작 코드와 대조해서 다시 고치게 됩니다.
- **옮기지 않은 함수는 조용히 빠집니다.** 데미지 숫자나 퇴각 대사가 그랬습니다. 재구현 방식의 약점이라, 원작 함수 목록과 대조하는 점검이 필요합니다.
- **엔딩까지 자동 진행 시험**이 있었기 때문에 5일 동안 수십 번 고쳐도 게임이 깨지지 않았습니다.

## 직접 빌드하기

### 준비물
- **원작 《삼국지 조조전》 설치본** (직접 가지고 있어야 합니다)
- (선택) 원작 CD 이미지: CD 음악과 동영상용
- [Rust](https://rustup.rs/) + WebAssembly 대상: `rustup target add wasm32-unknown-unknown`
- (선택) CD 음악 변환: macOS `afconvert`, 동영상 변환: `ffmpeg`

### 1. 원작에서 자료 꺼내기
```sh
cargo build --release
./target/release/ekd5 extract "<조조전 설치 폴더>" data      # E5·EEX·WAV, 아이콘, 튜토리얼 대사
python3 -I scripts/extract-cd.py "<CD 이미지.ccd>" data       # (선택) CD 음악 BGMnn.m4a, 동영상 mp4
```
`data/` 폴더는 원작 저작물이라 `.gitignore`로 막혀 있습니다. **절대 커밋하거나 공개하지 마세요.**

### 2. 명령줄로 돌려 보기 (스크린샷)
```sh
# 2만 틱 동안, 1000틱마다 스크린샷을 shots/ 에
./target/release/ekd5 shots data shots 20000 1000

# 엔딩까지 자동 진행 회귀 시험 (끝에 "엔딩 0" 이 나오면 성공)
EKD5_AUTOPLAY=1 EKD5_CHEAT=1 EKD5_AUTO=6 EKD5_PRESS="20:20" \
  ./target/release/ekd5 shots data shots 700000 10000000
```
시험 옵션(`EKD5_STAGE`, `EKD5_TAPS`, `EKD5_QSAVE`, `EKD5_FORCE` 등)은 [`AGENTS.md`](AGENTS.md)에 있습니다.

### 3. 브라우저에서 하기
```sh
./scripts/build-web.sh             # web/ekd5_web.wasm 빌드, web/data → ../data 링크
python3 -m http.server -d web 8080 # http://localhost:8080
```
같은 와이파이의 휴대폰에서 `http://<컴퓨터 IP>:8080` 으로 접속할 수도 있습니다.

> 인터넷에 올리려면 원작 데이터가 함께 올라가므로 **반드시 비공개(접속 잠금)** 로 해야 합니다. 이 프로젝트는 Cloudflare Pages + 비밀번호 미들웨어(`scripts/pages-functions/`)를 씁니다.

## 저작권 안내

- 《삼국지 조조전》의 프로그램, 그림, 음악, 글, 데이터의 저작권은 **KOEI TECMO GAMES**(구 KOEI)에 있습니다.
- 이 저장소에는 원작의 데이터 파일, 실행 파일, 디컴파일 결과가 **포함되어 있지 않습니다.** 엔진을 돌리려면 정식으로 가진 원작이 필요합니다.
- 이 프로젝트는 원작을 기리고 보존 기술을 연구하는 개인의 비영리 프로젝트이며, KOEI TECMO와 관계가 없습니다.
- 원작 데이터를 포함한 빌드를 공개된 곳에 배포하지 마세요.
