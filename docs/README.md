# 기술 문서 — 옛날 PC 게임을 웹으로 재구현한 전 과정

《삼국지 조조전》(KOEI, 1998) 엔진을 Rust/WASM으로 다시 만든 과정을, 다른 사람이 **자기 게임에 그대로 적용해 볼 수 있게** 정리했습니다. 이 게임에만 해당하는 값보다 **방법과 함정**을 중심으로 썼습니다.

| 장 | 내용 |
|---|---|
| [1. 역공학 준비](01-reverse-engineering-setup.md) | Ghidra 를 화면 없이 돌려 전체 디컴파일, 스크립트 명령 표 찾기, 리소스·문자열 직접 읽기 |
| [2. 데이터 형식 풀기](02-data-formats.md) | 압축 묶음, 팔레트, 글꼴, 스프라이트, 표 데이터, 메모리와 파일 배치가 다른 함정 |
| [3. 스크립트 엔진](03-script-engine.md) | 이벤트 바이트코드 구조, 명령 인자 서명표 만들기, 117개 파일 전수 검증 |
| [4. 원작 함수를 옮기는 법](04-porting-functions.md) | 디컴파일 코드 읽는 요령, 증상 → 원작 함수 추적, 시간 단위 환산 |
| [5. 시험 체계](05-testing.md) | 화면 없는 자동 진행 회귀 시험, 장면 재현 옵션, 브라우저 자동 시험 |
| [6. 웹·PWA](06-web-pwa.md) | WASM 경계 설계, 터치·회전 입력, 아이폰 소리 함정, 저장, 비공개 배포, 설치 안내 |
| [7. AI 와 일한 방식](07-working-with-ai.md) | 사람과 AI 의 역할, 작업 고리, 잘 된 점과 실패한 점 |
