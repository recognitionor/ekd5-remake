# 5. 시험 체계

재구현은 한 곳을 고치면 다른 곳이 깨지기 쉽습니다. 이 프로젝트가 5일 동안 수십 번 바뀌고도 끝까지 돌아간 이유는 **화면 없이 엔딩까지 자동으로 가는 회귀 시험** 덕분입니다.

## 5.1 엔진을 화면과 분리한다

엔진(`crates/ekd5`)은 입력과 출력을 이렇게만 주고받습니다.
- 입력: `set_input(누른 키, 마우스 위치, 눌림)` + 매 틱 `tick()`
- 출력: 팔레트 화면 버퍼, 소리·이벤트 목록, 받아야 할 파일 목록

그래서 같은 엔진을 브라우저(`ekd5-web`)에서도, 명령줄(`ekd5-cli`)에서도 돌릴 수 있습니다. 명령줄에서는 파일을 바로 읽고 화면은 PNG 로 저장합니다.

## 5.2 엔딩까지 자동 진행

```sh
EKD5_AUTOPLAY=1 EKD5_CHEAT=1 EKD5_AUTO=6 EKD5_PRESS="20:20" \
  ./target/release/ekd5 shots data shots 700000 10000000
# … 끝에 "[426352] 엔딩 0" 이 나오면 성공
```

| 옵션 | 뜻 |
|---|---|
| `EKD5_AUTOPLAY` | 내 차례도 AI 가 대신 둠, 본진 출진 자동, 로그 자세히 |
| `EKD5_CHEAT` | 아군은 강하게, 적은 1 데미지 → 지지 않고 끝까지 감 |
| `EKD5_AUTO=n` | n 틱마다 결정 키 (대사 넘기기) |
| `EKD5_PRESS=틱:키` | 그 틱에 키 |

58개 전투와 이야기 전체를 지나 엔딩까지 약 42만 틱, 몇 분이 걸립니다. **배포 전에는 항상** 이것을 돌렸습니다.

치트 없이 돌리면 실제 난이도로 진행되어 아군이 쓰러지고 퇴각하는 장면 등이 나옵니다. 퇴각 대사나 회심 외침을 확인할 때 썼습니다.

## 5.3 장면 재현 옵션

버그는 대개 특정 장면에서만 보입니다. 그 장면으로 바로 가는 옵션을 하나씩 늘렸습니다.

| 옵션 | 쓰임 |
|---|---|
| `EKD5_STAGE=n` | n 단계부터 시작 |
| `EKD5_SNAP` / `EKD5_RESTORE=문자열` | 단계마다 진행 상태 문자열 출력 / 그 상태에서 시작 |
| `EKD5_QSAVE=틱:파일` / `EKD5_QLOAD=파일` | 중간 저장 (전투 중, 본진) 쓰기 / 불러오기 |
| `EKD5_AUTOPLAY_END=틱`, `EKD5_AUTO_END=틱` | 그 틱부터 사람이 조작하는 상태로 |
| `EKD5_TAPS=틱:x:y,…` | 그 틱에 화면 좌표를 누름 |
| `EKD5_ALT=틱:x:y` | 정보 보기 (오른쪽 클릭·길게 누르기) |
| `EKD5_FORCE=틱:블록` | 사건 블록 강제 실행 (예: 일기토 장면) |
| `EKD5_TOOL=틱` | 도구 쓰기 연출 바로 시작 |
| `EKD5_FX=틱:번호` | 책략 연출 하나 재생 |

예: 본진 장비 화면을 열고 아이템을 고른 뒤 정보를 보는 화면을 찍기

```sh
EKD5_RESTORE="$(cat r14.txt)" EKD5_AUTO=6 EKD5_AUTO_END=1100 \
EKD5_TAPS="1240:300:300,1270:510:410,1290:100:72" EKD5_ALT="1330:100:72" \
  ./target/release/ekd5 shots data out 1350 10
```

`shots <자료> <폴더> <틱 수> <간격>` 은 간격마다 PNG 를 남깁니다. 여러 장을 한 장으로 붙여 보면 연출의 흐름을 한눈에 확인할 수 있습니다.

## 5.4 로그를 시험에 쓰기

자동 진행 중 엔진이 남기는 로그가 곧 시험 결과입니다.

```
[  1159] 아군 차례 1턴
[  1324] 공격 3→483
[ 19229] 퇴각 대사 하후연: …
[426352] 엔딩 0
```

새 기능을 넣을 때 로그 한 줄을 같이 넣으면, "그 장면이 실제로 나오는가"를 화면 없이 검색으로 확인할 수 있습니다.

## 5.5 계산만 따로 확인

공식이 원작과 같은지는 게임을 돌리지 않고 확인하는 편이 빠릅니다. 엔진 라이브러리를 불러 쓰는 작은 Rust 프로그램을 따로 만들어 확인했습니다.
- 장수 레벨별 능력치와 데미지 표
- 스크립트 전체를 훑어 특정 장수가 나오는 전투와 설정값 목록

## 5.6 브라우저 자동 시험 (Playwright)

웹에서만 생기는 문제(터치, 화면 회전, 소리, 설치 안내)는 Playwright 로 시험했습니다.
- 휴대폰 기기 흉내: `devices["iPhone 15 Pro"]`, 가로 모드, 사용자 에이전트 바꾸기(아이폰 크롬, 카카오톡)
- 터치와 길게 누르기: CDP `Input.dispatchTouchEvent` 로 touchStart, 기다리기, touchEnd
- 게임 좌표 → 화면 좌표 변환: 회전된 화면까지 고려
- 소리 확인: `addInitScript` 로 `AudioBufferSourceNode.prototype.start` 를 감싸서 실제 재생 횟수를 셈
- 설치 창: 가짜 `beforeinstallprompt` 이벤트를 보내 [설치하기] 단추 동작 확인

### 한계
시험 브라우저는 실제 아이폰이 아닙니다. 아이폰 Safari 의 소리 정책(앱 전환 뒤 멈춤 등)은 재현되지 않았습니다. 이런 부분은 실제 기기 확인을 사용자에게 부탁했고, 확인하지 못한 것은 확인하지 못했다고 적었습니다.
