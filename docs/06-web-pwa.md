# 6. 웹·PWA

엔진을 WebAssembly 로 감싸 휴대폰 브라우저에서 돌리고, 홈 화면에 설치하는 웹 앱(PWA)으로 만든 부분입니다.

## 6.1 WASM 경계 설계

`crates/ekd5-web/src/lib.rs` 는 `wasm-bindgen` 없이 `extern "C"` 함수 몇 개만 내보냅니다. 경계가 단순하면 디버깅이 쉽습니다.

| 함수 | 방향 | 하는 일 |
|---|---|---|
| `tick(키, x, y, 마우스 종류, 누름)` | JS → 엔진 | 한 틱 진행 |
| `frame()` | 엔진 → JS | 640×480 RGBA 화면 버퍼 주소 |
| `take_requests()` | 엔진 → JS | 받아야 할 파일 이름 목록 (줄바꿈 구분) |
| `provide(이름, 자료)` / `missing(이름)` | JS → 엔진 | 받은 파일 넘기기 / 없음 알리기 |
| `take_events()` | 엔진 → JS | 소리·음악·동영상·저장 이벤트 (JSON 줄) |
| `quick_save()` / `quick_restore()` | 양방향 | 중간 저장 문자열 |

### 파일은 필요할 때 받는다
엔진이 자료를 요청하면 `Pending` 을 받고 다음 틱에 다시 시도합니다. JS 는 요청 목록을 보고 `fetch` 해서 넘깁니다. 처음에 수십 MB 를 다 받지 않아도 되어 첫 화면이 빨리 뜹니다.

### 웹에서만 만드는 자료: `@txt/`
원작의 큰 제목 글자(굴림 굵게)는 글꼴 파일이 없습니다. 엔진이 `@txt/높이/글` 이라는 이름으로 자료를 요청하면, JS 가 캔버스에 그 글을 그려 0/1 마스크로 넘깁니다. 명령줄에서는 비트맵 글꼴을 확대해서 대신합니다.

## 6.2 입력

- **누름**: `pointerdown` 에서 결정 키를 짧게 누른 것처럼 보내고(`pulse`), 누르고 있는 동안은 결정 키를 계속 보냅니다(끌어서 지도 스크롤).
- **정보 보기**(원작 오른쪽 클릭): 마우스 오른쪽 단추 또는 **0.45초 길게 누르기**(12px 이상 움직이면 취소). `tick` 의 누름 인자 비트 2 로 보냅니다.
- **마우스와 터치 구분**: 마우스는 올려 두기만 해도 고르기(원작처럼), 터치는 올려 두기가 없어서 "한 번 누르면 고르기, 다시 누르면 실행"으로 바꿨습니다. `tick` 의 마우스 종류 인자(1 터치, 2 마우스)로 알려 줍니다.
- **화면 회전 좌표**: 아이폰은 화면 방향 고정 API 가 없어서, 가로 고정을 고르면 앱 전체를 CSS 로 90도 돌립니다. 그러면 터치 좌표도 같이 돌려야 합니다 (`toGame()`).

## 6.3 소리 — 아이폰 함정

- 효과음은 **Web Audio** 로 냅니다. 파일마다 한 번만 받아 풀어 두고 재사용합니다. 매번 `new Audio()` 를 쓰면 늦고 버벅입니다.
- 배경음악은 `<audio>` 요소로 냅니다.
- **첫 터치 전에는 소리를 낼 수 없습니다.** 첫 터치 때 `AudioContext` 를 만들거나 깨웁니다.
- **앱 전환·화면 잠금 뒤** 아이폰 `AudioContext` 가 멈춘 채 남는 일이 있습니다. 상태가 `running` 인데 소리가 안 나기도 합니다. 그래서 화면에 다시 돌아온 뒤 첫 터치 때 `AudioContext` 를 **새로 만듭니다**. 풀어 둔 소리 버퍼는 그대로 다시 씁니다.
- `navigator.audioSession.type`: 배경음악을 켜면 `playback`(무음 스위치 무시), 끄면 `ambient`(다른 앱 음악과 같이 남) 으로 바꿉니다.

## 6.4 저장

- `localStorage` 에 저장합니다.
  - 단계 자동 저장: `ekd5-save`
  - 저장 칸 5개: `ekd5-slot-1..5`
  - 회차 공통 기록(엔딩, 보물도감): `ekd5-common`
- 중간 저장은 엔진 상태(진행 중인 스크립트 위치 포함)를 JSON 으로 만듭니다.
- **저장 형식이 바뀌어도 예전 저장이 열리게**: 새 칸에는 `#[serde(default)]` 를 붙입니다. 엔진 버그로 잘못 저장된 값은 불러올 때 고칩니다. 예: 장비 번호 변환 버그로 잘못 들어간 장비를 `fix_legacy_gear` 로 교정.
- 난수: 원작은 전투마다 시각으로 씨앗을 정합니다. 웹도 불러올 때마다 새 씨앗을 써서 "불러오면 같은 결과" 문제를 없앴습니다.

## 6.5 비공개 배포 (Cloudflare Pages)

원작 데이터가 함께 올라가므로 **반드시 잠가야** 합니다. `scripts/pages-functions/_middleware.js`:
- 비밀번호는 Cloudflare secret(`SITE_PASSWORD`)에 둡니다. 없으면 모든 요청을 거부합니다(fail closed).
- 로그인 방법은 세 가지입니다.
  1. 전용 링크(`?k=토큰`)
  2. 로그인 화면에서 비밀번호 → 쿠키 (홈 화면 앱에서도 됨)
  3. HTTP Basic Auth (시험 도구용)
- 쿠키에는 비밀번호 대신 해시를 넣습니다.
- `data/` 응답은 `Cache-Control: private, max-age=86400` 로 브라우저에 하루 보관합니다.

배포: `./scripts/deploy.sh` 가 WASM 빌드 → `deploy/public` 복사 → `version.txt`(현재 시각) → `wrangler pages deploy` 순서로 합니다.

## 6.6 PWA

- `manifest.webmanifest`: `display: fullscreen`, 가로 방향, 아이콘. 사이트가 잠겨 있어서 `<link rel="manifest" crossorigin="use-credentials">` 가 필요합니다.
- `sw.js`: 설치 조건을 채우기 위한 서비스 워커입니다. **캐시는 하지 않습니다.** 항상 최신을 받고, 잠금도 그대로 적용됩니다.
- **새 버전 알림**: 홈 화면 앱은 새로고침 단추가 없습니다. 주기적으로 `version.txt` 를 확인해서, 바뀌었으면 "새 버전이 있습니다" 단추를 띄웁니다.

### 설치 안내 (`web/install.js`)
자동 설치는 어떤 브라우저도 허락하지 않습니다. 처음 접속 때 한 번만 안내합니다.

| 환경 | 할 수 있는 것 |
|---|---|
| 안드로이드 크롬·삼성 인터넷, PC 크롬·엣지 | `beforeinstallprompt` 를 잡아 두었다가 [설치하기] 단추로 `prompt()` |
| 아이폰 사파리 | API 없음 → "아래 공유 → 홈 화면에 추가" 안내 |
| 아이폰 크롬 (`CriOS`) | API 없음 → "주소창 옆 공유 → 홈 화면에 추가" 안내 (iOS 16.4+) |
| 카톡 등 앱 안 브라우저 | 설치 불가 → 외부 브라우저로 열라고 안내 |
| 설치된 앱으로 실행 (`display-mode: standalone/fullscreen`) | 안 띄움 |

`beforeinstallprompt` 는 페이지 초기에 오므로, 게임 스크립트보다 **먼저 실행되는 별도 파일**에서 잡습니다.

## 6.7 화면

- 엔진 화면은 640×480 팔레트 버퍼입니다. JS 가 매 프레임 RGBA 로 받아 캔버스에 `putImageData` 합니다. 확대는 CSS `image-rendering: pixelated` 로 합니다.
- 폰에서 원작의 바둑판 무늬 반투명(이동 범위 표시)이 뭉개져 통으로 보였습니다. 그래서 RGBA 로 바꿀 때 반반 섞는 반투명으로 대신했습니다 (`Screen.glaze`).
